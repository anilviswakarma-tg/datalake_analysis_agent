Self-hosted copies of the fonts the Streamlit app used, taken from the
`streamlit` package so the Chainlit UI looks the same without calling
Google Fonts.

- `SourceSansVF-*.woff2` - Source Sans 3, Adobe. SIL Open Font License 1.1.
- `MaterialSymbolsRounded.woff2` - Material Symbols, Google. Apache License 2.0.
