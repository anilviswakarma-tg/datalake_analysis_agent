# Data Lake Agent

Ask questions in plain English across the catalogue, playlog, user and store
domains. The agent looks up the data dictionary, writes and runs the Athena
SQL, then shows you the results, with CSV and Excel downloads for anything
longer than a single number.

- **Pick an agent** from the menu at the top left to see its suggested questions.
- **Pick a model** from the dropdown under the message box.
- **Dev mode** (the ⚙️ settings) shows the agent's tool calls, SQL and query ids.

Answers come from live data, but the agent can still get things wrong. Check
anything important, and follow up if a number looks off.

Access is restricted to @tunedglobal.com accounts.
